# demo-app

Proyecto de FIXTURE para `evals/run.py` (plugin custom-agents). Contenido inventado: una
aplicación mínima con una iniciativa `demo` en `docs/roadmap/` y dos entradas de memoria técnica en
`docs/knowledge/` (un gotcha de CSV y una lección de estimación) para que los prompts de los
evals tengan un contexto realista (spec aprobada, evaluación go, plan en borrador).
