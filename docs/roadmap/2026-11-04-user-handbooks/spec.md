# Manuales de uso eficiente y resultados de calidad

Petición explícita del usuario: manual detallado para aprovechar una cuenta de unos 20 USD de Claude o Codex y otro para sacar el máximo partido de custom-agents. El histórico exige documentos comprensibles, workflows completos, ejemplos y diagramas, con PDF moderno. Publicación mediante commits y push ya autorizada.

## Alcance y aceptación

- Dos manuales en español, fuentes Markdown y dos PDF independientes, sin sustituir el manual operativo existente.
- Uso eficiente: cuota frente a contexto y API, interfaces y comandos reales, modelo/esfuerzo, lecturas, memoria, herramientas, perfil lite, reintentos, rutina, prompts y límites de las estimaciones de ahorro.
- Calidad: recorrido completo del core, responsabilidades, decisiones, artefactos, aceptación, ejemplos trabajados, diagnóstico, revisión/QA, integraciones opcionales, memoria, personalización, entrega y recuperación.
- Fuentes oficiales actuales para condiciones de proveedores; no prometer resultados perfectos, cuotas fijas ni ahorro de dinero no medido.
- Diagramas Mermaid en Markdown y renderizados en PDF; índices, marcadores, enlaces y tipografía legible; revisión visual y de integridad del contenido.
- Enlaces en índices ES/EN y README; ledger y evidencia públicos sin configuración o corpus privados.

No se cambian modelos, políticas, configuración de usuario, runtime ni suscripciones. No se lanzan sesiones de pago para fabricar una medición. TDD n/a para prosa y maquetación; se aplican las comprobaciones documentales y de distribución pertinentes.
