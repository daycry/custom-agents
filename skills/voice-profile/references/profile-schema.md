# Esquema del perfil

Usa los campos necesarios para el encargo; no exige una base de datos ni un fichero.

| Campo | Contenido |
|---|---|
| Ámbito | Autor identificado por el usuario, objetivo, audiencia y canales incluidos |
| Muestras | ID local, origen autorizado, fecha si se conoce, canal y tramo relevante |
| Rasgo | Observación, ejemplos por ID, contraejemplo, alcance y evidencia limitada/suficiente/contradictoria |
| Preferencias confirmadas | Decisiones expresas del autor, separadas de inferencias |
| Exclusiones | Temas, datos y dispositivos expresivos que el autor quiere evitar |
| Revisión | Fecha del análisis, cambios respecto al perfil anterior y dudas abiertas |

Busca rasgos que cambien decisiones: ritmo y longitud de frases, compresión de
ideas, capitalización, paréntesis, preguntas, vocabulario, forma de argumentar,
grado de certeza y llamadas a la acción. No rellenes todos por obligación.
Una muletilla aislada o una errata no son necesariamente una preferencia.

Si el autor alterna tutoriales y mensajes comerciales, conserva reglas por canal.
Ante contradicción entre muestras y preferencia expresa, aplica la preferencia al
nuevo texto y registra el contraste; no reescribas la evidencia histórica.

Para comprobar utilidad, aplica dos o tres rasgos a un párrafo autorizado y muestra
qué cambió. El ejemplo acredita aplicación, no que el autor haya aprobado el perfil.
Conserva solo citas necesarias; no copies el corpus íntegro al perfil persistido.
