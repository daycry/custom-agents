# Revisión de red

Elige amplitud por objetivo: mantener relaciones actuales, extender a perfiles
próximos o explorar nuevos sectores y mercados. No impongas un número de contactos.
Registra exclusiones indicadas por el usuario antes de proponer candidatos.

Para cada inventario conserva origen, fecha, tipo de relación, identificador y
alcance. No mezcles seguidores con conexiones aceptadas ni una exportación parcial
con el universo completo. Ante duplicados, resuelve identidad; no fusiones por nombre.

Propón conservar, revisar, ampliar o retirar con motivo observable. Retirar es una
propuesta, no una acción realizada. La prioridad puede apoyarse en objetivo común,
interacción confirmada o pertinencia del rol; no en una puntuación ficticia de
influencia o de valor puente. Si falta actividad, escribe desconocida, no inactiva.

Para cada recomendación ofrece una siguiente acción proporcional: retomar una
conversación, preparar una pregunta, comprobar identidad o dejar la relación como
está. No consulta mensajes ni enriquece perfiles de forma automática para completar
todas las celdas de una tabla.
